# LANnventory v0.1.0-beta.10.uat.5

## Summary

This is a focused Phase 35.10 follow-up UAT build based on real-environment feedback from `v0.1.0-beta.10.uat.4`.

UAT4 simplified the Host navigation into a flat tab strip, but the strip was still slightly wider than the Device Overview card because the Host card lived inside a Bootstrap column while the navigation strip was rendered outside that same column.

UAT5 fixes that structural alignment issue.

### Host navigation alignment

- Moves the Host navigation strip into the same Bootstrap `col-12` as the Device Overview card.
- Ensures Device Overview and Inventory / Network / Activity share the exact same left and right boundaries.
- Keeps the flat tab-strip design and active underline from UAT4.
- Keeps the compact Device Overview introduced in UAT3.
- Keeps selected content close to the navigation strip.

### Regression protection

- Adds a semantic regression check requiring Device Overview and local Host navigation to share the same Host column.
- Adds a width constraint check so the navigation border remains inside the same column geometry.

### Existing Phase 35.10 behavior retained

- Only one Host section is visible at a time.
- Proxmox Workloads remain collapsed by default.
- Secondary expandable sections retain clear Show details / Hide details affordances.
- Services, Identity, Presence and Proxmox behavior are unchanged.
- Presence browser-local day/timezone handling remains intact.
- Restart-safe updater behavior remains unchanged.

## UAT upgrade path

Upgrade from **v0.1.0-beta.10.uat.4** using:

1. **Settings → Updates**
2. Update channel: **Beta**
3. **Check now**
4. Confirm that **v0.1.0-beta.10.uat.5** is offered.
5. Start the update through the LANnventory updater.

## UAT focus after upgrade

### Host geometry

- Device Overview and the Inventory / Network / Activity strip should have identical left and right edges.
- The tab strip should no longer appear wider than the Host card.
- The flat active underline should remain clear.
- The navigation should continue to look visually attached to the Host overview.

### Existing behavior

- Compact Host summary remains intact.
- Only one section is displayed at a time.
- Workloads remain collapsed initially.
- Show details / Hide details controls remain obvious.
- Host actions, Services, Identity, Presence and Proxmox controls continue to work as before.

## Release status

Phase 35.10 follow-up UAT candidate. Do not merge into `main` until real-environment UAT is explicitly approved.
