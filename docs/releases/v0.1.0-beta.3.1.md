# LANnventory v0.1.0-beta.3.1

## Summary

- Separate **automatic update checks** from **automatic installation**.
- Allow background checks to notify only, without installing anything.
- Show a visible **Update <version>** reminder in the top-right navigation when a newer release is detected.
- Keep navbar polling local by reading cached update status instead of triggering GitHub checks.
- Open release notes inside LANnventory first, with a concise curated summary and a separate **View full release on GitHub** link.
- Preserve beta.3 behavior for existing users: automatic installation still implies automatic checks.

## Validation

- Frontend build and embedded-bundle verification.
- Backend unit tests, race detector, vet and build.
- Docker build, Compose validation and safe container smoke test.
- GoReleaser snapshot and package-content validation.
- Check-only scheduler test confirms no install is scheduled.
- Cached navbar status test confirms no release-server request is made.

## Notes

This is a beta test release intended to validate the notification-only update workflow and local release-notes experience on the Proxmox/Debian package installation.
