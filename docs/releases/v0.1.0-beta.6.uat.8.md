# LANnventory v0.1.0-beta.6.uat.8

## Summary

- Adds a lightweight Home summary for Proxmox hypervisor Hosts showing the current number of **LXC containers** and **VMs**.
- Counts come from the full imported infrastructure workload inventory, not only workloads already linked to LANnventory Hosts.
- Both running and stopped workloads count because both still exist in current Proxmox inventory.
- Retired workloads are excluded from the Home totals.
- **Comfortable** view shows the totals on a second line under the Proxmox Host name.
- **Compact** view keeps the device row one-line by showing the same totals inline beside the Proxmox Host name.
- The summary is read-only and uses the already imported Phase 35 workload inventory; it does not query or modify Proxmox and does not introduce Phase 35.8 automatic sync.

## UAT focus

Upgrade from v0.1.0-beta.6.uat.7 through Settings → Updates on the Beta channel.

Verify:
- the Proxmox Host row shows an inventory summary such as `24 LXC · 8 VM`;
- Comfortable shows that summary below the Proxmox name;
- Compact keeps the full row on one line and shows the totals inline;
- totals include both running and stopped current workloads;
- totals do not depend on how many workloads have been matched/linked to LANnventory Hosts;
- retired workloads are not included;
- guest Host rows still show their existing VM/LXC relationship marker and are not confused with the parent-hypervisor totals;
- filtering, sorting, Comfortable/Compact persistence, and Host navigation continue to work normally.
