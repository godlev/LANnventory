# LANnventory v0.1.0-beta.10.uat.4

## Summary

This is a focused Phase 35.10 follow-up UAT build based on real-environment feedback from `v0.1.0-beta.10.uat.3`.

UAT3 improved the compact Host overview, but the local Inventory / Network / Activity navigation still looked visually displaced because it combined an outer footer strip with an inner bordered pill container and a boxed active tab.

UAT4 simplifies that structure into a single flat tab strip.

### Host navigation

- Removes the nested bordered/pill container around the Host tabs.
- Keeps **Inventory / Network / Activity** directly on the Host navigation strip.
- Uses a simple active-tab underline instead of another boxed control.
- Reduces the visual layering between Device Overview, local navigation, and selected content.
- Tightens the vertical spacing between the tab strip and the active section.
- Keeps keyboard focus behavior and the one-section-at-a-time layout from UAT2/UAT3.

### Existing Phase 35.10 behavior retained

- Compact Device Overview remains in place.
- Proxmox Workloads remain collapsed by default.
- Secondary expandable areas retain clear Show details / Hide details affordances.
- Services, Identity, Presence and Proxmox behavior are unchanged.
- Presence browser-local day/timezone handling remains intact.
- The restart-safe updater continues to report real stages and recovery information.

## UAT upgrade path

Upgrade from **v0.1.0-beta.10.uat.3** using:

1. **Settings → Updates**
2. Update channel: **Beta**
3. **Check now**
4. Confirm that **v0.1.0-beta.10.uat.4** is offered.
5. Start the update through the LANnventory updater.

## UAT focus after upgrade

### Host navigation

- Inventory / Network / Activity should read as one simple navigation strip, not nested pills.
- The active tab should be obvious from its underline.
- There should be no oversized empty footer area around the tabs.
- Selected content should begin close to the navigation strip.
- Device Overview should remain compact and visually connected to the Host navigation.

### Existing behavior

- Only one Host section should be visible at a time.
- Workloads remain collapsed initially.
- Show details / Hide details controls remain obvious.
- Host edit/actions, Services, Identity, Presence and Proxmox controls continue to work as before.

## Release status

Phase 35.10 follow-up UAT candidate. Do not merge into `main` until real-environment UAT is explicitly approved.
