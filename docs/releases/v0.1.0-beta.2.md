# LANnventory v0.1.0-beta.2

LANnventory v0.1.0-beta.2 is a beta release candidate. It focuses on Events usability, mobile/responsive polish, runtime reliability and the first official Proxmox VE LXC installer.

## Highlights

- Substantially improved Events filtering and grouping.
- Stable cursor-based Events pagination.
- Correct relative event times across server/browser timezone differences.
- Mobile and responsive layout fixes across Home, Events and Presence.
- Runtime startup failure handling suitable for systemd retry.
- Official Debian 13 Proxmox VE LXC installer.

## Events

- Added Event Type multi-selection.
- Added Device multi-selection.
- Added ordered multi-level grouping by device, event, category, device type, IP, interface and day.
- Added stable cursor pagination using event date and ID, while keeping legacy offset pagination available.
- Hardened Events filtering/grouping error paths.
- Fixed a cursor reactivity issue that could leave the Events table showing zero loaded events.
- Added an optional `DateUTC` display timestamp so relative event times are independent of browser timezone.

## UI / Mobile

- Improved mobile Events layout.
- Improved Presence mobile layout.
- Fixed Home responsive width and horizontal overflow problems.
- Refined Home mobile summary cards.
- Fixed Home inline name-edit focus behavior.
- Improved Events filter indicators, dropdown clipping and multiselect checkbox semantics.

## Reliability

- Startup and bind failures now return a fatal process error so systemd can restart the service.
- The systemd unit uses `Restart=on-failure`.
- Graceful shutdown behavior is preserved.

## Proxmox

- Added an official interactive Proxmox VE installer for a Debian 13 amd64 LXC.
- The container is unprivileged by default.
- The installer detects CT ID, rootfs storage, template storage and Linux bridges.
- `vmbr0` is preferred when available; Proxmox firewall bridges are excluded.
- DHCP and static IPv4 are supported.
- The installer seeds `IFACES: "eth0"` and restarts the service after writing configuration.
- The installer validates service state, `/api/health`, `/api/version` and `arp-scan` availability.
- The tested environment did not require privileged mode, nesting, AppArmor relaxation or broad capabilities.

## API / Packaging

- Swagger/API documentation was refreshed.
- Events cursor parameters `beforeDate` and `beforeId` are documented.
- Events responses include additive `DateUTC` display data where available.
- Existing release artifact formats continue: `tar.gz`, `.deb`, `.rpm`, `.apk` and `checksums.txt`.
- No Docker registry image is published by this release pipeline.

## Installation / Upgrade Notes

- This is intended to be a compatible beta upgrade from `v0.1.0-beta.1`.
- No manual database migration is required.
- No manual configuration migration is required.
- Events pagination additions are backward-compatible; legacy offset pagination remains supported.
- `HostEvent.DateUTC` is additive and does not replace `HostEvent.Date`.
- Back up existing `config_v2.yaml`, `scan.db`, `scan.db-wal` and `scan.db-shm` before upgrading a real installation.

## Known Limitations

- LANnventory does not include built-in authentication. Use it on a trusted LAN, through a VPN, or behind an authenticated reverse proxy / SSO layer.
- LANnventory is still beta software, so UI and API details may continue to evolve before a stable release.
- Old timezone-less historical Event timestamps cannot always have their original timezone reconstructed if the server timezone changed after they were written.
- PostgreSQL support remains present, but SQLite is the primary packaging-validated path for this beta.
