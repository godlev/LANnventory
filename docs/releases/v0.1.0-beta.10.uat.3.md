# LANnventory v0.1.0-beta.10.uat.3

## Summary

This is a focused Phase 35.10 follow-up UAT build based on real-environment feedback from `v0.1.0-beta.10.uat.2`.

UAT2 confirmed that the staged updater flow is working end to end, including backup creation, restart, health verification, reconnect/resume, and final version confirmation. The remaining Host-page feedback was visual: the Device Overview header still consumed too much vertical space, and the Inventory / Network / Activity tabs looked detached from the Host overview.

UAT3 addresses those two findings without changing Host data behavior.

### Compact Device Overview

- Reduces the height and padding of the Host summary header.
- Uses a smaller device icon and tighter name/status treatment.
- Keeps Device Type, IP, MAC, Owner and Location visible while consolidating them into a compact summary line.
- Keeps edit, Wake-on-LAN, Known/Unknown, Pin and overflow actions available in the same overview.

### Integrated Host navigation

- Keeps the existing **Inventory / Network / Activity** structure introduced in UAT2.
- Visually attaches the local navigation directly to the bottom of the Device Overview card.
- Removes the detached/floating-tab appearance.
- Reduces tab height and spacing while preserving the active state and keyboard focus behavior.
- Maintains the one-section-at-a-time layout so the Host page remains substantially shorter than UAT1.

### Updater status

The updater flow observed during the UAT1 → UAT2 upgrade passed the intended staged-update behavior:

- Real stages were displayed instead of fake percentage progress.
- A recovery backup was created and reported.
- LANnventory restarted and returned healthy.
- The UI completed with the actually installed version `0.1.0-beta.10.uat.2`.

No updater behavior is intentionally changed in UAT3.

## UAT upgrade path

Upgrade from **v0.1.0-beta.10.uat.2** using:

1. **Settings → Updates**
2. Update channel: **Beta**
3. **Check now**
4. Confirm that **v0.1.0-beta.10.uat.3** is offered.
5. Start the update through the LANnventory updater.

## UAT focus after upgrade

### Host overview

- The top Device Overview should be visibly shorter than UAT2.
- Name, status, Device Type, IP, MAC, Owner and Location remain easy to identify.
- Host actions remain accessible without increasing the header height significantly.

### Host local navigation

- Inventory / Network / Activity should look like part of the same Host shell as Device Overview.
- The tabs should no longer look like a separate floating control with a large empty gap around it.
- Active section state should remain obvious.
- Only one secondary Host section should be visible at a time.

### Existing UAT2 behavior

- Proxmox Workloads remain collapsed by default.
- Secondary expandable sections retain clear Show details / Hide details affordances.
- Services, Identity, Presence and Proxmox behavior remain unchanged.
- Presence browser-local day/timezone handling remains intact.
- Updater remains restart-safe and reports real progress stages.

## Release status

Phase 35.10 follow-up UAT candidate. Do not merge into `main` until real-environment UAT is explicitly approved.
