# LANnventory v0.1.0-beta.6.uat.2

## Summary

This Phase 35A follow-up keeps the UAT1 Proxmox data model and safety rules unchanged, while making the onboarding flow understandable without repository knowledge.

- Adds a visible data-source legend for Manual, Discovered and Imported information.
- Adds per-field provenance icons/tooltips to managed Device Profile fields.
- Clarifies that Proxmox version, node name and cluster name in the managed profile are optional manual reference values; imported observations remain separate.
- Replaces the raw JSON-first import form with a four-step Proxmox import wizard.
- Explains exactly how collector permissions work: the collector runs locally on the Proxmox node and inherits the shell user's permissions; LANnventory does not need a Proxmox password or API token.
- Adds a copy-ready command that downloads the collector from the running LANnventory instance and executes it on the Proxmox node.
- Adds a local Download collector fallback for nodes that cannot fetch the LANnventory URL directly.
- Packages the exact allowlisted collector inside the LANnventory binary and regression-tests that the canonical, frontend and embedded collector copies remain identical.
- Keeps Preview mandatory before Apply and preserves all UAT1 import validation, transaction, retirement and workload matching safeguards.

## UAT focus

Upgrade from v0.1.0-beta.6.uat.1 through Settings → Updates on the Beta channel, then verify:
- the updater offers and installs v0.1.0-beta.6.uat.2;
- Device Profile clearly shows Manual / Discovered / Imported provenance guidance;
- managed profile fields show source information and optional Proxmox reference fields are understandable;
- the Proxmox Inventory panel shows a four-step import wizard instead of an unexplained JSON box;
- the wizard explains that the collector must be run in the Proxmox shell as root or another user allowed to run qm/pct and read the allowlisted /etc/pve network lines;
- Copy produces a command using this LANnventory instance's URL;
- Download collector returns lannventory-proxmox-collector.py from the installed LANnventory instance;
- running the command on the Proxmox node prints JSON without asking for Proxmox credentials;
- pasting/uploading that JSON and choosing Preview changes shows the expected diff before Apply;
- Apply, workloads and Host matching continue to behave as in UAT1.
