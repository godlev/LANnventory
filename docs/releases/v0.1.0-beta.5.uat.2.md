# LANnventory v0.1.0-beta.5.uat.2

## Summary

- Clarifies Host → Network & Discovery with Current IP, Current MAC, Vendor, and MAC-scoped lifecycle labels.
- Renames the identity panel to Network identity history and makes shared-IP reuse explicit: an IP observed with another MAC is address history, not proof of the same physical device.
- Keeps same-device correlation visually and semantically separate from IP reuse history; the correlation algorithm and decisions are unchanged.
- Host → Recent events now shows Event, historical IP, historical MAC, and time from each stored event snapshot, without redundant links back to the same Host page.
- Adds responsive Host event layout and regression checks that preserve Global Events Host links and handle missing historical IP/MAC safely.
