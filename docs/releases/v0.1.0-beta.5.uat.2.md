# LANnventory v0.1.0-beta.5.uat.2

## Summary

- Clarifies Host Details as current network identity: Current IP, Current MAC, MAC type, Interface, Network vendor, and MAC-scoped first/last seen timestamps.
- Renames the observation area to Network identity history and makes shared-IP history explicit: an IP reused by another MAC is not a same-physical-device conclusion.
- Keeps same-device correlation visibly separate from IP reuse history; correlation scoring and user decisions are unchanged.
- Host Recent Events now show Event, historical IP snapshot, historical MAC snapshot, and Time, without redundant links back to the same Host page.
- Adds responsive stacking for Host Recent Events and regression contracts preserving global Events Host links and missing IP/MAC fallbacks.

## UAT focus

Update from v0.1.0-beta.5.uat.1 through Settings → Updates on the Beta channel. Verify the Host page with a reused IP, the separation between IP history and same-device correlation, historical event IP/MAC snapshots, and narrow/mobile layout.

Phase 34 UAT usability correction. This prerelease is for updater UAT only and is not the final Phase 34 merge or stable release.
