# LANnventory v0.1.0-beta.10.uat.6

## Summary

This Phase 35.10 UAT build replaces the previous sequence of incremental Host layout fixes with a structural Host workspace refactor.

The refactor was implemented after repeated UAT feedback showed that local CSS and Bootstrap gutter adjustments were creating new layout regressions while fixing previous ones.

### Structural Host workspace refactor

- Replaces the stitched Bootstrap row/column composition with one shared `.host-workspace` shell.
- Keeps Device Overview, Host-local navigation and the selected Host section inside the same structural container.
- Removes the previous `host-primary-shell`, separate Host rows/columns and negative-margin compensation path.
- Keeps **Inventory / Network / Activity** as explicit Host-local sections.
- Keeps only one secondary Host section visible at a time.
- Keeps the selected content in a dedicated `.host-section-content` area with a simple internal stack.

### Host overview

- Keeps the compact Host summary introduced during earlier Phase 35.10 UAT iterations.
- Name, status, device type, IP, MAC, owner and location remain visible.
- Existing edit, Wake-on-LAN, Known/Unknown, Pin/Home and overflow actions remain available.
- Managed Information and Current Network provenance remain distinct.

### Progressive disclosure

- Proxmox Workloads remain collapsed by default.
- Secondary technical sections retain explicit **Show details / Hide details** affordances.
- Services, Identity, Presence and Proxmox behavior are unchanged.

### Regression tests

- Host UX regression checks now validate the intended structural contract instead of exact incidental CSS values.
- Tests require:
  - one shared Host workspace;
  - explicit Host-local navigation;
  - selected Host content inside the same workspace;
  - one active secondary section at a time;
  - Proxmox workloads collapsed by default;
  - visible disclosure affordances;
  - no return to the previous compensated Bootstrap Host layout.

### Embedded frontend

The generated frontend bundle was rebuilt and synchronized using the repository's normal `make all` production path, including the required `/fs/public/assets/` path rewriting used by the embedded backend frontend.

## UAT focus after upgrade

### Host layout

- Device Overview, Host navigation and selected content should read as one coherent workspace.
- Inventory / Network / Activity should no longer appear detached or wider/narrower because of separate Bootstrap gutters.
- There should be no unexplained empty footer strip or nested pill container.
- Selected content should align naturally with the Host workspace.
- The page should remain materially shorter than the original UAT1 layout.

### Responsive behavior

Check:
- desktop;
- narrow desktop/tablet;
- mobile around 390–430 px.

There should be no horizontal overflow, clipped IP/MAC values, overlapping controls or tab width regressions.

### Existing behavior

Confirm that:
- only one Host section is visible at a time;
- Proxmox Workloads remain collapsed initially;
- Show details / Hide details controls remain clear;
- Host edit/actions continue to work;
- Services, Identity, Presence and Proxmox controls remain functional.
