# LANnventory v0.1.0-beta.6.uat.3

## Summary

- Fixes a Proxmox collector bug found during Phase 35A UAT where snapshot sections in guest configuration files could emit duplicate network interfaces.
- Collector 1.0.1 now reads only the active Proxmox configuration section before snapshot blocks, preventing historical network values from being imported as current state.
- LXC network parsing also deduplicates repeated netN keys defensively.
- Adds a regression test based on the observed CT129 case where eth0 appeared three times and caused Preview validation to stop with a duplicate-interface error.
- Keeps the UAT2 guided collector wizard and data-source provenance UX unchanged.

## UAT focus

Upgrade from v0.1.0-beta.6.uat.2 through Settings → Updates on the Beta channel.

Re-run the collector from the Proxmox Host wizard. Confirm:
- collectorVersion is 1.0.1;
- the collector completes without collectionErrors;
- each workload has unique interface names;
- the previously failing LANnventory CT no longer produces duplicate eth0 rows;
- Preview accepts the snapshot and displays the workload diff;
- no data is written before Apply is confirmed.

## Release status

Phase 35A bugfix UAT. Phase 35.8 Proxmox API credentials/automatic sync remains intentionally out of scope until UAT is approved.
