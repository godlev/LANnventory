# LANnventory v0.1.0-beta.6.uat.7

## Summary

- Adds two Home → Devices table presentation modes: **Comfortable** and **Compact**.
- Keeps **Comfortable** as the default and preserves the current richer layout, including the second-line Proxmox workload ancestry.
- Adds a true one-line **Compact** mode with reduced row padding and no second-line Proxmox metadata.
- In Compact mode, a linked Proxmox workload is represented beside the Host name by only a VM/LXC-specific icon and its numeric VMID/CTID.
- Keeps the full workload/parent relationship available through the marker tooltip and the Host details page.
- Persists the selected Home table view in browser local storage, so the preferred density survives refresh/reopen on that browser.
- Compact mode is presentation-only: it does not change Host data, matching, links, filters, sorting, or Proxmox inventory semantics.
- Mobile device rows keep their existing expandable details behavior rather than being forced into the desktop Compact layout.

## UAT focus

Upgrade from v0.1.0-beta.6.uat.6 through Settings → Updates on the Beta channel.

Verify:
- the Devices toolbar offers **Comfortable** and **Compact**;
- Comfortable is the default on a browser with no saved preference;
- switching to Compact immediately reduces row height and keeps each desktop device entry on one line;
- linked Proxmox guests no longer show a second line such as `VM 112 · PROXMOX` in Compact mode;
- instead, Compact shows only a workload-type icon plus the VMID/CTID beside the Host name;
- hovering the compact marker still explains the linked Proxmox workload/parent;
- switching back to Comfortable restores the existing second-line ancestry display;
- refreshing the page preserves the selected table view in the same browser;
- filtering, sorting, pinning, editing, online/offline indication, and Host navigation continue to work in both modes;
- mobile expanded details still show the full Hosted on relationship.
