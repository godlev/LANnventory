# LANnventory v0.1.0-beta.6.uat.1

## Summary

- Adds managed Device Profiles with typed Network, System, and Hypervisor capability data while keeping imported/discovered data separate from user-managed fields.
- Models Proxmox VMs and LXC containers as infrastructure workloads instead of creating fake LANnventory Hosts.
- Adds a read-only Proxmox collector that exports an allowlisted JSON snapshot without credentials, Internet transfer, raw configs, disks, tokens, keys, or guest data.
- Adds strict snapshot validation plus Preview/Diff before any import can be applied; incomplete snapshots and manual/import conflicts are blocked safely.
- Reconciles complete imports transactionally, retains retired workloads, and preserves manual data and manual workload links.
- Adds workload-to-Host matching: a unique exact MAC can auto-link; address and name evidence remain explainable suggestions requiring user choice.
- Adds a dedicated responsive Proxmox Host panel with source state, workload status, network identity, Host matches, and the collector Preview/Apply workflow.

## UAT focus

Upgrade from v0.1.0-beta.6 through Settings → Updates on the Beta channel. Verify:
- the one-click updater installs v0.1.0-beta.6.uat.1 and LANnventory returns healthy after restart;
- a Server can be configured with the Proxmox VE hypervisor capability without becoming a separate Hypervisor device type;
- managed Device Profile values remain separate from imported Proxmox values;
- the read-only collector JSON can be pasted or uploaded and Preview shows Add / Update / Unchanged / Retire / Conflicts before Apply;
- Apply requires confirmation and a valid preview, then shows node/source state and VM/LXC workloads;
- exact-MAC workload matches link automatically only when deterministic;
- address/name matches are suggestions only, ambiguous matches require a manual choice, and manual links are preserved;
- existing Home, Host, Identity, Services, Events, Presence, scanner diagnostics, scheduled scans, and updater behavior remain intact.
