# LANnventory v0.1.0-beta.6

## Summary

- Adds a persistent Services inventory per device address, protocol and port, with First Detected, Last Detected, Last Checked and current open/closed state.
- Manual TCP port scans now persist definitive observations and emit service-opened/service-closed Events only on real state transitions.
- Failed, timed-out, unreachable and cancelled probes remain indeterminate and never fabricate a service closure.
- Adds opt-in per-device scheduled TCP service scanning with configurable ports/interval, bounded concurrency, cancellation safety and stale in-flight result protection.
- Adds IPv4/IPv6-aware address attribution through the Phase 33 identity/address model and conservative common-port service hints.
- Clarifies Host network identity and history: Current IP/MAC, vendor/MAC lifecycle wording, explicit IP-reuse semantics, and same-device correlation separation.
- Host Recent Events now shows each event's historical IP and MAC snapshots with a responsive layout and no redundant self-links.

## Upgrade and migration

- Services and scheduled-scan settings use additive database migrations.
- Existing WatchYourLAN/LANnventory data remains compatible; no destructive migration is introduced.
- Existing updater backup, package install, restart, health verification and recovery behavior is unchanged.

## Validation

- Updater UAT covered v0.1.0-beta.5.uat.1 and the approved Host UX correction v0.1.0-beta.5.uat.2; beta.6 selection is regression-tested from beta.5, uat.1 and uat.2.
- Phase 32 scanner/diagnostics and Phase 33 identity/address regression suites remain green.
- Host UX semantic regression checks, historical event snapshot tests, full test/race/vet/frontend, Docker/container and release-artifact validation passed before final Beta publication.
