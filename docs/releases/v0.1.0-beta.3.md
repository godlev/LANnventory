# LANnventory v0.1.0-beta.3 — draft release notes

This document is a draft for the next beta release. The version is not published until the release tag is created and the tag-driven release workflow succeeds.

## Highlights

- Expanded Host inventory with Owner, Location, Notes, Tags and Home pinning.
- Added lifecycle tracking for First Seen and Last Seen, including explicit handling for migrated installations where First Seen is estimated from retained evidence.
- Added portable JSON backup export and current-inventory CSV export.
- Consolidated Host editing into a staged Save / Cancel workflow while keeping Known / Unknown and Pin / Unpin as immediate actions.
- Refined the Home device table and pinned-device grouping.
- Improved Host page proportions by giving Host Details more room and narrowing Port Scan.
- Added touch-friendly delayed tooltips with native browser title fallback.
- Added a Proxmox installer autostart prompt and fixed the documented bash -c installer invocation.

## Validation target before publishing

- Packaging Check green on the final release-candidate SHA.
- Release Artifact Dry Run green on the same final SHA.
- Frontend build and dependency audit pass.
- Backend tests, race detector, vet and build pass.
- Docker build, Compose validation and safe runtime smoke test pass.
- Proxmox installer syntax/helper tests pass.
- Manual browser review on desktop, mobile, dark and light themes.
- Verify the generated amd64 Debian package in a Proxmox LXC upgrade test from v0.1.0-beta.2.

## Not part of beta.3

- Persistent port-state intelligence and port opened/closed Events.
- Stable/Beta one-click self-update.
- Built-in authentication.
- Full PostgreSQL runtime validation.
