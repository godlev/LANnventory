# LANnventory v0.1.0-beta.3

## Highlights

### Inventory and dashboard UX
- Refined Home connectivity/recognition summary cards for a denser responsive layout.
- Simplified Home summary presentation and added current-Unknown device scope in Events.
- Consolidated and tightened Events summary cards on desktop and mobile.

### Host details and port activity
- Redesigned Host details actions and information layout.
- Added adaptive action tooltips with hover/focus support, touch long-press behavior and native browser fallback.
- Refined Host details / Port Scan proportions across desktop breakpoints.
- Newly discovered open ports can be recorded as Host activity events.

### Software updates
- Added **Settings → Updates** with Stable and Beta channels.
- Added one-click release checking and update installation for supported Debian-package/systemd installations.
- Added optional **Automatic updates**.
- Added automatic check intervals of **6 hours, 12 hours, 24 hours, or 7 days**.
- Update scheduling is rescheduled immediately when channel, automatic-update or interval settings change; no restart is required.
- Added last-checked time and snapshot-base information.
- Added a header update-available indicator/popover with update and review actions.
- Shared update status keeps the Settings panel and header notification consistent.

### Update safety
- Selects only official LANnventory GitHub Releases from the configured channel.
- Requires a matching Debian architecture package and `checksums.txt`.
- Verifies SHA256 and, when available, the GitHub asset digest before installation.
- Creates a versioned recovery backup under `/var/lib/lannventory/update-backups`.
- Stops LANnventory before copying `/etc/watchyourlan` so SQLite/config data is backed up consistently.
- Restarts LANnventory and validates `/api/health` using the configured bind host and port.
- Preserves and reports the recovery backup path if an update cannot complete cleanly.

### Release and packaging hardening
- Packaging Check verifies committed embedded frontend assets match frontend source.
- Release dry runs and tag-driven releases rebuild the current frontend before GoReleaser.
- Release artifact validation covers expected Linux architectures plus DEB/RPM/APK/archive contents.
- Debian/RPM packaging includes updater runtime requirements such as CA certificates and curl.

## Known beta limitations

- PostgreSQL runtime deployment still requires full real-database integration validation; SQLite remains the primary validated path.
- Automatic package installation is currently limited to supported Debian-package/systemd installations.
- Docker, RPM, APK and manual-binary deployments should continue to use their normal deployment/update method.
- LANnventory does not yet provide built-in authentication; keep it on a trusted LAN/VPN or behind an authenticated proxy.
