# LANnventory v0.1.0-beta.9

## Summary

LANnventory 0.1.0-beta.9 is the finalized Phase 35.8 release with the read-only Proxmox API inventory integration validated in real-environment UAT.

Functionally it carries the same Phase 35.8 implementation validated through `v0.1.0-beta.8.uat.1` and `v0.1.0-beta.8.uat.2`.

## Why beta.9 follows beta.8

The Phase 35.8 UAT builds were published as `beta.8.uat.x`. LANnventory's updater uses standard SemVer precedence, where `beta.8.uat.2` sorts after `beta.8`.

The established LANnventory release convention avoids that ambiguity by advancing the final beta number after UAT (for example `beta.6.uat.x → beta.7`). Therefore `beta.9` is the correct updater-visible final release that supersedes both the Phase 35.8 UAT builds and the intermediate `beta.8` release.

No Phase 35.8 functionality was changed for this sequencing correction.

## Phase 35.8 highlights

- Optional read-only Proxmox API inventory source.
- Dedicated write-only API token secret storage.
- HTTPS-only endpoint configuration with TLS verification enabled by default.
- Non-mutating Test Connection.
- Manual Sync now → Preview/Diff → explicit Apply.
- Cluster/node provenance for workloads.
- Exact-MAC linking protection and preserved manual links.
- Safe retirement semantics and history preservation.
- API → node-local script cross-source retirement protection.
- Last-good inventory preservation on authentication, TLS, timeout and partial-collection failures.
- Idempotent repeated sync.
- GET-only Proxmox API client; no control operations.
- Periodic/scheduled sync remains deferred to Phase 35.9.

## UAT validation

Real-environment UAT on Proxmox VE 9.2.20 validated:

- dedicated privilege-separated token with `Sys.Audit` + `VM.Audit`;
- TLS fail-closed behavior and trusted Proxmox CA operation with verification enabled;
- non-mutating connection tests;
- first reviewed API Apply;
- preservation of existing exact-MAC links;
- retirement of a genuinely removed LXC without deletion;
- unchanged repeat sync: `0 Add / 0 Update / 31 Unchanged / 0 Retire / 0 Conflicts`;
- authentication failure preserving last-good inventory;
- clean recovery after credentials are restored;
- removal of the false `9.2.20` vs `pve-manager/9.2.20` warning.

## Upgrade path

Beta channel users on `v0.1.0-beta.7`, `v0.1.0-beta.8`, or Phase 35.8 UAT builds should converge on `v0.1.0-beta.9`.
