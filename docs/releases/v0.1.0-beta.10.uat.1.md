# LANnventory v0.1.0-beta.10.uat.1

## Summary

This is the first UAT build for **Phase 35.10 — Full Host + Settings UX Review & Redesign**.

The build focuses on clearer information hierarchy, explicit managed/discovered provenance, safer progressive disclosure, responsive Host/Settings layouts, and a truthful restart-safe updater experience.

### Host

- Reworks the Host page around a first-class **Device Overview** instead of a stack of unrelated feature cards.
- Separates **Managed information** from **Current network / Discovered · Read only** data.
- Keeps destructive device actions secondary to normal edit and status actions.
- Makes empty Device Profile state compact while retaining managed/imported provenance.
- Prioritizes **current open services**; manual scanning, historical services and scheduled scanning are secondary disclosures.
- Separates current network identity from identity history and keeps shared-IP evidence explicitly non-conclusive.
- Makes Proxmox inventory summary/workloads primary while moving connection, collection and source details behind progressive disclosure.
- Improves Host Recent Events partial-error handling and retry behavior.
- Adds responsive labelled-row layouts for Services and Proxmox workload tables.

### Presence history

- Fixes browser-local calendar-day filtering when LANnventory stores history timestamps in a different server/container timezone.
- The selected Presence date now maps to the correct UTC interval for the browser's local day, including DST transition days.
- Returned presence timestamps are rendered in the browser timezone before day/night classification.
- Changing the date triggers a real refetch instead of relying on a forced remount.
- Presence now distinguishes **Loading**, **no data for this date**, and **API failure**, with a local Retry action.

### Settings

- Adds explicit section navigation for General, Network discovery, Diagnostics, Data & retention, Updates, Integrations and About, including a mobile selector.
- Makes per-section save behavior explicit instead of implying one global Save.
- Clearly distinguishes settings that require Save from update preferences that save immediately.
- Standardizes write-only secret UX for Shoutrrr, PostgreSQL and InfluxDB: stored values are never displayed back to the browser and clearing remains explicit.
- Improves responsive Settings layout and section hierarchy.

### Updater UX and recovery

- Adds durable update-attempt state so progress survives LANnventory restart and browser refresh.
- Reports real backend stages only: **Preparing → Downloading → Verifying → Creating backup → Installing → Restarting → Health check → Complete**.
- Does not invent percentage completion.
- Persists attempt/version/timestamps, backup state/path, failure stage and service-recovery state.
- Reconciles interrupted/stale update attempts instead of leaving LANnventory permanently marked as updating.
- The browser resumes an active update after refresh and treats the expected restart disconnect as part of the update flow.
- Completion is verified against the actually installed backend version.
- Failure UI identifies the failed stage, backup/recovery state and exposes Retry only when safe.

## UAT upgrade path

Upgrade from **v0.1.0-beta.10** using:

1. **Settings → Updates**
2. Update channel: **Beta**
3. **Check now**
4. Confirm that **v0.1.0-beta.10.uat.1** is offered.
5. Start the update through the LANnventory updater.

During the update, verify that the UI advances only through real stages and that a temporary disconnect during restart is presented as expected. After reconnect, verify that the installed version is **0.1.0-beta.10.uat.1** and existing configuration/database data remain intact.

## UAT focus after upgrade

### Host

- Device Overview clearly presents name/type/status/IP/MAC.
- Managed and discovered/read-only information are visually distinct.
- Edit/Save/Cancel and Known/Unknown/Pin/Wake behavior remain correct.
- Services show current open state first; manual and scheduled scans still work.
- Identity history and possible same-device evidence remain separate and non-misleading.
- Device Profile edit/save works and empty profiles remain compact.
- Proxmox workloads, matching, API connection, manual sync and Automatic Sync remain functional.
- Recent Events load normally and expose a local error/retry state if their request fails.

### Presence

Pay particular attention around local midnight.

- Selecting **today** must show samples belonging to the browser-local calendar day even when the backend/container clock uses UTC.
- Selecting yesterday must continue to work.
- Changing dates must refetch immediately.
- A valid day with no samples must show a clear empty state rather than a blank panel.
- Day/night colors and sample timestamps should correspond to browser-local time.

### Settings

- Section navigation works on desktop and narrow/mobile layouts.
- Explicit-save sections retain their changes after Save and refresh.
- Update preferences save immediately.
- Stored Shoutrrr/PostgreSQL/InfluxDB secrets remain hidden and explicit clearing works.
- No important field, IP/MAC value or action is inaccessible on narrow layouts.

## Scope

This UAT build does **not** start the Unknown Device Identification Toolkit or Phase 36 router/network-source integrations.
