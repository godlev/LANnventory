# LANnventory v0.1.0-beta.6.uat.9

## Summary

- Fixes Home Proxmox VM/LXC totals not appearing on installations where the current Host MAC is stored in lowercase while imported workload ownership uses canonical uppercase MAC.
- The workload summary API now resolves the managed hypervisor profile using the current Host's stored MAC representation after the canonical workload owner has been mapped back to that Host.
- Adds regression coverage using a lowercase discovered Host MAC and canonicalized workload inventory ownership.
- Adds mock API support for the workload summary endpoint so local frontend validation exercises the same Home behavior.

## UAT focus

Upgrade from v0.1.0-beta.6.uat.8 through Settings → Updates on the Beta channel.

Verify:
- the PROXMOX Home row now shows the VM/LXC totals;
- Comfortable view shows the totals below PROXMOX;
- Compact view shows the totals inline while keeping the row one line;
- the totals match current non-retired Proxmox inventory and include both running and stopped workloads;
- guest Host VM/LXC markers remain unchanged.
